# QuantumMatter 1.2.0 API additions

Version 1.2 adds seven Core declarations to the unchanged
[1.0.0 API baseline](1.0.0.md), giving 218 shipped declarations. Exact signatures,
nullable annotations and defaults are frozen in PublicAPI.Shipped.txt and shipped
in the package alongside compiler-checked XML documentation.

| Member | Contract |
| --- | --- |
| PauliString(string operators) | Immutable validated 1–30 uppercase I/X/Y/Z labels; rightmost label acts on q0 |
| PauliString.Operators | Original validated labels |
| PauliString.QubitCount | Label count including identity factors |
| StateVector.MarginalProbability(ReadOnlySpan&lt;int&gt; qubits, int outcome, CancellationToken cancellationToken = default) | Normalized marginal Born probability; no mutation |
| StateVector.Measure(ReadOnlySpan&lt;int&gt; qubits, Random random, CancellationToken cancellationToken = default) | Packed subset outcome and phase-preserving branch projection |
| StateVector.ExpectationValue(PauliString observable, CancellationToken cancellationToken = default) | Real normalized Pauli expectation without sampling or mutation |

The type declaration itself accounts for the seventh added inventory entry.
Selections are nonempty, distinct and in range. Bit k of outcome corresponds to
qubits[k]. Observable length must match the state. Invalid arguments use standard
argument exceptions; invalid total Born mass uses InvalidOperationException.

Queries scan host amplitudes in O(2^n) time with constant auxiliary storage.
Measurement cancels before commit without mutation; its final O(2^n) projection
is noncancellable. Existing MeasureAll and Run contracts are preserved. See the
[observation guide](../observations.md) for formulas, examples and limitations.
