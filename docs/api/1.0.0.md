# QuantumMatter 1.0.0 API reference

This reference describes the selected 1.0.0 contract; see the release record for
publication status. Every public source member has compiler-checked XML documentation shipped
beside its assembly. Exact declarations, nullable annotations, default arguments
and enum values are frozen in each library's PublicAPI.Shipped.txt and included
under api/ in its package. Future additions belong in PublicAPI.Unshipped.txt.

Core depends only on .NET. Application references Core. Infrastructure references
Core and ILGPU. No public signature exposes an ILGPU, driver, HTTP or persistence
type. The application never creates a concrete backend; the caller supplies and
owns it. No dependency-injection container is required.

## Circuits and gates

QuantumCircuit(qubits) accepts 1–30 and allocates no state. Operations is a live
read-only view; fluent gates append in execution order. Targets must be in range,
all operands distinct where applicable, and angles finite radians. GateKind numeric
identifiers 0–16 are fixed. GateOperation retains its four-argument construction and
deconstruction while also carrying SecondControl and an optional custom unitary.
It is descriptive data; executable circuits are constructed through validated gates.

H/X/Y/Z/S/T/I/Sdg/Tdg, Rx/Ry/Rz/Phase, CNot/Swap/Toffoli, built-in Controlled and
convenience controlled gates, U and ControlledU form the release gate set.
SingleQubitUnitary.Create copies/validates a 2x2 matrix or four row-major entries;
entries must be finite, columns orthonormal within absolute 1e-12. Adjoint preserves
the immutable value. See [matrices and controls](../gates.md).

StateVector(qubits, memoryBudgetBytes) owns an all-zero-initialized pure state.
Amplitude and Probability validate basis indices; Snapshot allocates an owned copy.
Reset restores |0...0> on the host. Evolve and EvolveTrajectory lend the private
buffer synchronously to trusted backends. MeasureAll samples actual Born mass and
collapses to a basis state with amplitude +1. Qubit zero is the least significant
bit; printed kets place it on the right. See [mathematics](../mathematics.md).

## Workflows and results

StateVectorSimulator(backend, options = null):

| Method | Result and resource contract |
| --- | --- |
| Simulate(circuit, cancellationToken = default) | Fresh unmeasured StateVector, 16N host bytes |
| Run(circuit, shots = 1024, seed = null, cancellationToken = default) | Evolves once; immutable counts, uncollapsed mutable FinalState; 24N host bytes |

SimulationOptions.MemoryBudgetBytes defaults to 512 MiB and must be positive.
Budgets exclude counts, snapshots, circuit/runtime overhead and backend allocations.
Shots must be positive. Counts use zero-padded strings and sum to Shots. Mutating
FinalState later does not recompute Counts. Seed guarantees are runtime/backend
scoped; see [compatibility](../compatibility.md).

NoisyStateVectorSimulator(unitaryBackend, noiseBackend, options = null):

| Method | Result and resource contract |
| --- | --- |
| SimulateTrajectory(circuit, seed = null, cancellationToken = default) | One conditional pure StateVector, 16N bytes |
| Run(circuit, shots = 1024, seed = null, cancellationToken = default) | Fresh trajectory per measured shot, immutable Counts/Shot count; 16N bytes |
| EstimateProbabilities(circuit, trajectories = 1024, seed = null, cancellationToken = default) | Mean Born probabilities and standard errors via Estimate(index); at least two trajectories; 32N bytes |

N = 2^qubits. NoiseChannel factories accept [0,1]: BitFlip, PhaseFlip, Depolarizing,
AmplitudeDamping. NoisyCircuit.Append snapshots a same-sized unitary segment;
ApplyNoise inserts one explicit channel. Depolarizing uses replacement strength p,
not Pauli-error probability p. Results represent an ensemble without a FinalState
ket. Standard errors measure trajectory sampling, not terminal measurement/model
uncertainty. Full definitions are in the [noise guide](../noise.md).

## Algorithms

- QuantumFourierTransform.CreateCircuit(qubits, inverse = false) and Append for
  a whole circuit or required ordered subset, with cancellation tokens, include
  final bit reversal. Local qubit order is least to most significant.
- DeutschJozsa.CreateCircuit(truthTable) requires a power-of-two constant/balanced
  Boolean table for 1–16 input qubits and generates zero-returning scratch bits.
- GroverSearch.CreateCircuit(inputQubits, markedBasisIndex, iterations = null) uses
  an explicit single marked solution and RecommendedIterations when unspecified.

Deutsch–Jozsa/Grover preflight a one-million-operation synthesis limit. Their logical
input limit is not a memory promise. All methods propagate CancellationToken;
Append cancellation can leave partial appended gates. See [algorithms](../algorithms.md).

## Backend extensions and hardware

IStateVectorBackend.Execute(circuit, Memory&lt;Complex&gt;, token) receives the complete
circuit and an arbitrary normalized state. Validate length, apply insertion order,
preserve phase/norm, complete synchronously and retain no buffer. Cancellation may
leave partial output. No matrices of dimension N by N are needed.

INoiseChannelBackend.Apply(channel, target, Memory&lt;Complex&gt;, Random, token) samples
one normalized conditional channel branch. Nonunitary normalization belongs here;
it does not weaken the unitary backend contract. Backends are trusted extensions,
not a sandbox. Neither circuit nor input buffer may be mutated concurrently.

Scalar CPU is stateless. Parallel CPU validates 1–256 workers, a 1–30-qubit threshold
(default 16), and optional SIMD (default false). Default workers are min(CPU count,4).
See [CPU execution](../cpu-performance.md) for supported paths and measurements.

CUDA construction validates options and creates/owns a device context. GetDevices
returns compatible visible devices; no device means an explicit capability error,
never automatic CPU fallback. State and staging budgets each default to 512 MiB.
ExecuteProfiled needs EnableProfiling=true and reports a CUDA kernel-sequence event
interval, including dispatch gaps but excluding transfers. Dispose is idempotent
and waits for active work. Calls on one CUDA backend serialize. See [GPU execution](../gpu-execution.md).

## Errors, cancellation and concurrency

| Failure | Contract |
| --- | --- |
| Required null input | ArgumentNullException |
| Invalid range, index, probability, angle or numeric option | ArgumentOutOfRangeException |
| Wrong buffer/matrix/register dimensions, duplicate qubits, invalid promise/unitary | ArgumentException (or its documented subclass) |
| Host workflow budget | ArgumentOutOfRangeException before allocation |
| CUDA state/staging budget | InvalidOperationException before state allocation |
| Nonfinite/nonpositive measurement or damping mass | InvalidOperationException |
| Missing CUDA capability/platform | PlatformNotSupportedException |
| CUDA profiling disabled | InvalidOperationException |
| CUDA instance disposed | ObjectDisposedException for otherwise valid execution input |
| Cancellation | OperationCanceledException carrying the caller token; parallel workers can aggregate technical failures |
| Actual allocation, driver or compiler failure | Original technical exception; no success or implicit fallback |

Exception messages and precedence for multiple invalid arguments are not stable
contracts. Expected argument/capability errors remain exceptions in this numerical
SDK. There is no HTTP result or business-domain error translation layer.

Simulators are reusable for independent buffers and immutable-in-use circuits, if
their injected backends support that usage. Circuit/state mutation is not thread
safe. Cancellation is cooperative: allocations/clears, active CUDA work and the
CUDA host commit are not preempted. A direct Evolve can leave partial state; a
workflow never returns partial work as a successful result.
