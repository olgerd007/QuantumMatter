# QuantumMatter 1.6.0 API additions

Version 1.6 adds 33 Application.Variational declarations to the 283 declarations
shipped through [1.5.0](1.5.0.md), for 316 total. Exact signatures, nullability,
parameter names, defaults and enum values are frozen in the packaged
Application/PublicAPI.Shipped.txt file. Core and backend ports are unchanged.

## Solver and options

VqeSolver(IStateVectorBackend backend, VqeOptions? options = null,
SimulationOptions? simulationOptions = null) injects a caller-owned backend and
immutable optimization/allocation policies. Solve(ParameterizedCircuit circuit,
PauliHamiltonian hamiltonian, ReadOnlySpan<double> initialParameters,
CancellationToken cancellationToken = default) returns VqeResult.

VqeOptions has eight init-only settings, validated when constructing the solver:
MaximumIterations, MaximumCircuitEvaluations, MaximumLineSearchIterations,
GradientTolerance, InitialStepSize, MinimumStepSize, BacktrackingFactor and
SufficientDecrease. Defaults, allowed ranges and mathematical definitions are in
the [VQE guide](../vqe.md).

## Results and termination

VqeResult exposes immutable Parameters, Energy, IterationCount,
EnergyEvaluationCount, GradientEvaluationCount, CircuitEvaluationCount and
TerminationReason. The result is the last accepted iterate, excluding rejected
trials even if their energy is lower but fails sufficient decrease.

VqeTerminationReason has stable values GradientToleranceReached=0,
IterationLimitReached=1, EvaluationLimitReached=2 and LineSearchStalled=3.
Stationarity is not a global-minimum guarantee. Cancellation and numerical/backend
failures throw without returning a successful partial result.

Every gradient call costs 1+2R circuit executions, where R counts symbolic
rotation occurrences, including shared parameters. Standalone initial/trial
energies cost one each. A complete gradient must fit before execution. Host-array
preflight conservatively requires 16N+48P+8T bytes, including overlapping nested
evaluator buffers; metadata and CUDA device/staging budgets are separate.
