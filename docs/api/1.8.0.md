# v1.8 API additions

Version 1.8 preserves the 316 declarations shipped through v1.6 and freezes four
accessor declarations for two opt-in Infrastructure properties already validated
in the 1.8.0-rc.1 candidate. Core, Application and backend-port contracts are
unchanged. No declaration is removed or rewritten.

| Property on ParallelCpuOptions | Shipped accessors | Default | Behavior |
| --- | --- | --- | --- |
| EnableAvx512 | bool get; init; | false | Requests supported 512-bit SIMD kernels when EnableSimd is enabled; retains portable fallback |
| EnableGateBlocking | bool get; init; | false | Reuses tiles across up to 32 adjacent uncontrolled same-target gates while preserving insertion order |

Gate blocking may use up to 16 KiB of stack workspace per active worker, outside
the state-array budget. AVX-512 is guarded by supported instructions, accelerated
vectors and the verified Complex layout. These controls do not change precision,
qubit indexing, gate order, backend ownership or existing default selections.

The educational quantum-cryptography examples and authenticated-PQC lab remain
internal repository tooling. They add no SDK cryptography protocol or runtime
dependency. See the [release record](../releases/1.8.0.md),
[CPU guide](../cpu-performance.md) and [security lab guide](../authenticated-pqc.md).
