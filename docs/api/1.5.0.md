# QuantumMatter 1.5.0 API additions

Version 1.5 adds 28 declarations to the 255 declarations shipped through
[1.4.0](1.4.0.md), for 283 total. Exact signatures, nullability, parameter names
and defaults are frozen in the packaged Core/Application PublicAPI.Shipped.txt files.

## Core observables and variational circuits

- PauliTerm(double coefficient, PauliString observable) is immutable and rejects
  nonfinite coefficients. Coefficient and Observable are read-only.
- PauliHamiltonian(int qubits, IReadOnlyList<PauliTerm> terms) copies its terms,
  validates matching widths and exposes QubitCount and immutable Terms. Empty sums
  are zero; duplicates and zero terms retain their order.
- StateVector.ExpectationEnergy(PauliHamiltonian hamiltonian, CancellationToken
  cancellationToken = default) returns the normalized, compensated real energy
  without mutating amplitudes or allocating a dense operator.
- ParameterizedCircuit(int qubits, int parameterCount) exposes QubitCount,
  ParameterCount, OperationCount and read-only RotationParameterIndices.
  Append(QuantumCircuit circuit) snapshots constant gates. Rx/Ry/Rz(int target,
  int parameterIndex) add uncontrolled symbolic rotations. Shared and unused
  parameters are supported.
- Bind(ReadOnlySpan<double> parameters, CancellationToken cancellationToken = default)
  creates an independently owned QuantumCircuit from an exact-width finite binding.
- BindWithRotationShift(ReadOnlySpan<double> parameters, int rotationIndex,
  double shift, CancellationToken cancellationToken = default) composes an offset
  on one symbolic occurrence, retaining the offset at very large bound angles.

## Application variational evaluation

VariationalEnergyEvaluator(IStateVectorBackend backend, SimulationOptions? options = null)
retains caller-owned backend lifetime. Evaluate(circuit, hamiltonian, parameters,
cancellationToken = default) returns energy. EvaluateWithGradient with the same
arguments returns immutable VariationalEnergyResult.Energy and Gradient.

Gradients sum each occurrence's parameter-shift contribution. Observable differences
are formed before coefficient weighting, protecting small gradients from large
identity offsets. Execution reuses one state initialized to zero for every circuit.
Required host arrays are 16N bytes for energy and 16N + 24P + 8T for gradients,
where N=2^qubits, P is parameter count and T is term count. Circuit metadata and
device/staging allocations are separate. Cancellation and backend failures propagate;
nonfinite numerical results fail explicitly.

These APIs support exact pure-state energies with uncontrolled Rx/Ry/Rz parameters.
Optimizers, noise/dynamic gradients, parameter expressions and controlled symbolic
rotations are outside this release. See the [variational guide](../variational.md)
for formulas, examples, ownership and numerical limits.
