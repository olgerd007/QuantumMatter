# QuantumMatter 1.2.0

QuantumMatter 1.2 adds partial-register measurement and Pauli observables while
preserving the existing state-vector, circuit and backend contracts.

## Install

Use matching package versions; Core is included transitively:

```sh
dotnet add package QuantumMatter.Application --version 1.2.0
dotnet add package QuantumMatter.Infrastructure --version 1.2.0
```

The [release record](1.2.0.md) tracks publication and validation evidence.

## Changes

- Measure an ordered subset of qubits while retaining spectator coherence and
  surviving complex phase.
- Query normalized marginal Born probabilities without changing the state.
- Evaluate immutable I/X/Y/Z Pauli strings exactly from state amplitudes, without shots.
- Run observations in O(2^n) time with constant auxiliary storage and no full matrices.
- Use the same host observation semantics after scalar, parallel/SIMD or CUDA evolution.
- Validate new APIs through a separate package-only consumer, alongside unchanged
  consumers compiled against published 1.0.0.

Seven additive declarations bring the shipped API inventory to 218. The existing
211 declarations and assembly binding version 1.0.0.0 remain compatible; file version
is 1.2.0.0. No new runtime dependency is introduced.

## Conventions and support

For subset selection, outcome bit k corresponds to qubits[k]. Pauli labels put
q0 on the right. The new probability/expectation queries divide by actual Born
mass; the existing Probability method still returns raw squared magnitude.
Partial Measure retains surviving phase, whereas MeasureAll keeps its existing
canonical +1 amplitude. Run continues terminal sampling without collapse.

All observations run on the host. Partial measurement performs cancellable scans
before a noncancellable projection commit. Dynamic circuit measurement, classical
control and GPU observation kernels are outside this release.

Libraries retain net9.0 assets for .NET 9/10 consumers. CPU support covers
Windows/Linux x64; CUDA support covers Windows x64, with Linux CUDA experimental.
See the [observation guide](../observations.md), [API additions](../api/1.2.0.md)
and [compatibility policy](../compatibility.md).

## Validation

The implementation candidate passes all eight Windows/Linux Debug/Release runtime
jobs. Local hardware-enabled suites pass 704 tests per runtime/configuration on
an RTX 4070 Ti SUPER; CPU-only suites pass 624 cases plus an explicit hardware skip.
Independent dense Pauli and projector oracles check phases, Y signs, ordering,
normalization and collapse. Fresh and baseline-compiled package consumers pass on
.NET 9/10, including real CUDA. Stable publication evidence is in the release record.
