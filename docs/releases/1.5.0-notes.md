# QuantumMatter 1.5.0

QuantumMatter 1.5 adds Pauli Hamiltonians and pure-state variational building blocks
while preserving the existing 1.x simulator and backend contracts.

## Install

Use matching package versions; Core is included transitively:

```sh
dotnet add package QuantumMatter.Application --version 1.5.0
dotnet add package QuantumMatter.Infrastructure --version 1.5.0
```

## Changes

- Immutable real Pauli sums and normalized state energy expectations.
- Parameterized Rx/Ry/Rz circuits with constant snapshots and shared/unused parameters.
- Energy evaluation and occurrence-wise parameter-shift gradients using existing backends.
- Termwise differences, compensated accumulation and composed shifts for large angles.
- Explicit host-array budgets, cancellation, immutable results and a runnable demo.
- Independent dense energy/derivative oracles and a fifth isolated package consumer.

The 28 additive declarations bring the shipped inventory to 283, preserving all
255 earlier declarations. Libraries retain net9.0 assets for .NET 9/10 consumers,
assembly binding 1.0.0.0 and the published 1.0.0 compatibility baseline. No runtime
dependency, project or backend interface is added.

## Conventions and limits

Angles are finite radians, rotations are exp(-i theta Pauli/2), qubit zero is least
significant and states are column vectors. Shared-parameter gradients sum shifted
occurrences separately. Energies use actual Born mass without mutating the state.

Reductions run on the host after existing scalar, parallel/SIMD or CUDA unitary
execution. Optimizers, stochastic/noisy/dynamic gradients, controlled symbolic
rotations and parameter expressions are outside this release. CPU support covers
Windows/Linux x64; CUDA is validated on Windows x64, with Linux CUDA experimental.
See the [variational guide](../variational.md), [API additions](../api/1.5.0.md)
and [compatibility policy](../compatibility.md).
