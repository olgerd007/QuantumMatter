# QuantumMatter 1.6.0

QuantumMatter 1.6 adds reusable pure-state VQE with deterministic gradient descent
and bounded backtracking, using the existing Hamiltonian/gradient evaluator.

## Install

Use matching package versions; Core is transitive:

```sh
dotnet add package QuantumMatter.Application --version 1.6.0
dotnet add package QuantumMatter.Infrastructure --version 1.6.0
```

## Changes

- VqeSolver searches from an independently owned finite parameter snapshot.
- Validated immutable options bound accepted updates, trial steps and all circuit executions.
- Armijo sufficient decrease handles extreme finite arithmetic and representability stalls.
- Immutable results distinguish stationarity, iteration/evaluation limits and stalled search.
- Exact accounting includes every occurrence-wise shifted preparation.
- Conservative overlapping-array budgets, cancellation and backend ownership are preserved.
- One-/two-qubit demos, independent analytic/dense checks and a sixth package consumer.

All 283 earlier declarations are preserved; 33 additions bring the shipped inventory
to 316. Library assets remain net9.0 for .NET 9/10 consumers, binding stays 1.0.0.0
and package validation retains published 1.0.0. No runtime project, dependency or
backend interface is added. See the [API additions](../api/1.6.0.md).

## Conventions and limits

The objective is a normalized pure-state Hamiltonian expectation with existing
rotation/endianness conventions. Shared parameters use occurrence-wise gradients.
Accepted steps must lower energy and satisfy sufficient decrease. Results contain
the last accepted iterate; stationarity can be a maximum, saddle or restricted
minimum, and finding a global ground state is not guaranteed.

Parameter updates, line search and reductions remain on the host. Existing scalar,
parallel/SIMD and CUDA backends prepare states. Noise/shot objectives, optimizer
plugins, bounds/restarts and device-resident optimization are outside this release.
See the [VQE guide](../vqe.md) and [compatibility policy](../compatibility.md).
