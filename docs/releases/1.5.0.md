## Scope and implementation

- Immutable PauliTerm/PauliHamiltonian descriptions and normalized state energy queries.
- ParameterizedCircuit snapshots constant gates and binds shared/unused Rx/Ry/Rz parameters.
- VariationalEnergyEvaluator reuses one state for energies and occurrence-wise gradients.
- Termwise shifted expectations, composed angle offsets, and compensated accumulation.
- A runnable example, independent dense derivative tests and a fifth package-only consumer.

All 255 earlier API declarations remain unchanged. Stable promotion freezes the
28 additions in Core/Application Shipped inventories, for 283 total. Assembly binding remains 1.0.0.0, library
assets remain net9.0, and the package-validation baseline remains published 1.0.0.
No project, runtime dependency or backend port is added. New APIs evaluate exact
pure-state expectations subject to floating-point precision; optimizers, shot-based
estimation, noise/dynamic gradients, controlled parameterized gates and parameter
expressions are outside this increment. See the [variational guide](../variational.md).
