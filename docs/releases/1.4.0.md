# 1.4 validation and publication record

Candidate version: **1.4.0-rc.1**. Stable promotion and publication are pending.
Implementation: [PR #12](https://github.com/olgerd007/QuantumMatter/pull/12).
Scope selected by the user: noisy dynamic circuits. The v1.3 release and its
public-indexing status are recorded [separately](1.3.0.md).

## Scope and implementation

- Core/Dynamic.NoisyDynamicCircuit composes private validated dynamic segments and
  explicit channel placements, preserving quantum state and classical history.
- StateVector.EvolveNoisyDynamic evolves an existing state with a new zero classical
  register and injected unitary/noise backends.
- Application/Dynamic.NoisyDynamicStateVectorSimulator executes independent histories
  and reuses DynamicTrajectoryResult/DynamicSimulationResult.
- A runnable demo and isolated NoisyDynamicConsumer cover the new package APIs.
- The public-feed check has an optional -ValidateNoisyDynamicCircuits mode; earlier
  versions remain usable without it.

All 240 shipped API declarations remain unchanged. Fifteen additions are in the
Core/Application Unshipped inventories. Assembly binding stays 1.0.0.0, library
assets remain net9.0, the package-validation baseline remains published 1.0.0,
and no new runtime dependency or backend interface is introduced.

Noise is explicit and unconditional. Existing unitary/noise/dynamic APIs retain
their semantics. Loops, conditional noise, correlated channels, automatic insertion
and device-resident noisy feedback are outside this increment. See the
[noisy dynamic guide](../noisy-dynamic-circuits.md) for mathematical and resource contracts.

## Validation

Baseline restore, zero-warning Debug build and 734 CUDA-enabled cases pass on
both .NET 9 and .NET 10 before implementation. The new 29 focused tests pass on
both runtimes, including actual CUDA. Candidate validation on Windows x64 with
SDK 10.0.402, runtimes 9.0.21/10.0.13 and an RTX 4070 Ti SUPER:

- Restore and Debug/Release builds pass with zero warnings or errors.
- All 763 CUDA-enabled tests pass per runtime in both Debug and Release.
- Release with CPU hardware intrinsics disabled passes all 763 cases per runtime.
- CPU-only Release passes 677 cases plus one explicit GPU-suite skip per runtime.
- Formatting verification and scalar, SIMD-selected and CUDA noisy dynamic demos pass.
- All three SDK packages validate against published 1.0.0. All four fresh package
  consumers pass CPU/SIMD/CUDA on both runtimes, with artifact/cache hashes checked.
- Unchanged 1.0.0-compiled consumer binaries run with candidate DLLs on both runtimes,
  including CUDA, while preserving their binary/dependency hashes.
- The extended public-feed checker still passes published 1.2.0 observation and
  baseline APIs on .NET 10 with CUDA and exact source metadata.
- All 29 Markdown files pass relative-link checks; git diff --check passes.
- The prerelease tag guard passes and rejects a stable v1.4.0 tag for this candidate.
- All 240 shipped API inventories and earlier consumer sources remain unchanged.

Remote Windows/Linux CI is tracked by PR #12. Stable API promotion, merging,
tagging and publication remain separate release steps.

Tests compare every supported channel/measurement branch against independent
dense Kraus matrices on arbitrary complex three-qubit inputs, including quantum
phases, classical-conditioned densities, reset and feedback across noise boundaries.
A separate exact branch oracle checks interleaved channels and classical overwrites;
seeded shot statistics use a bound above six worst-case binomial standard deviations.
Other cases cover snapshots, zero-strength draw preservation, old-workflow equivalence,
independent shots, immutable counts, allocation budgets, cancellation and failures.

```powershell
dotnet restore QuantumMatter.sln
dotnet build QuantumMatter.sln --no-restore -c Debug -p:EnableCudaTests=true
dotnet test QuantumMatter.sln --no-build --no-restore -c Debug -p:EnableCudaTests=true
dotnet build QuantumMatter.sln --no-restore -c Release -p:EnableCudaTests=true
dotnet test QuantumMatter.sln --no-build --no-restore -c Release -p:EnableCudaTests=true
dotnet format QuantumMatter.sln --no-restore --verify-no-changes
./scripts/Test-Packages.ps1 -Configuration Release -SkipBuild -EnableCuda
./scripts/Test-Packages.ps1 -Configuration Release -SkipBuild -ConsumerFramework net10.0 -EnableCuda
```

Package checks must restore all four sibling consumers from fresh candidate
packages and execute baseline-compiled binaries with replacement SDK DLLs without
rebuilding their app/dependency manifest. Local package success is not publication.
