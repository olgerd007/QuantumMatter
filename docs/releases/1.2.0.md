# 1.2 development and validation record

Candidate version: **1.2.0-rc.1**. Publication: **not published**.
Stable v1.1.0 remains available; stable promotion is pending.

## Scope

- Ordered partial-register projective measurement with phase-preserving collapse.
- Normalized marginal Born probabilities without mutation.
- Immutable Pauli strings and exact state-vector expectations without sampling.
- Constant auxiliary storage; explicit cancellation, resource and endianness contracts.
- Shared host operations after scalar, parallel/SIMD and CUDA preparation/evolution.

The seven additive Core API declarations belong in PublicAPI.Unshipped.txt.
The 211 shipped declarations, 1.x assembly binding version, net9.0 library assets
and published 1.0.0 package-validation baseline remain unchanged. No runtime
dependency is added. Full .NET 9/10 validation remains required.

Mathematics, examples, limitations and independent oracle design are in the
[observation guide](../observations.md). Dynamic circuit measurement, classical
control, reduced density matrices, weighted Hamiltonian models and GPU observation
kernels are outside this increment.

## Validation

Baseline before changes: restore and the complete Debug CUDA-enabled suite passed
666 tests on each runtime, on a compatible CUDA device.

Candidate validation on Windows x64 with project-selected SDK, runtimes .NET 9/.NET 10,
compatible CUDA device and compatible driver:

- Restore and Debug/Release builds pass with zero warnings or errors.
- Debug and Release each pass 704 tests per runtime with real CUDA enabled.
- Release with CPU intrinsics disabled also passes 704 tests per runtime.
- CPU-only Release passes 624 tests per runtime, with one explicit hardware-suite skip.
- Formatting verification and the scalar, SIMD-selected and CUDA observation demos pass.
- All three packages validate against published 1.0.0; seven additive API declarations
  leave shipped inventories unchanged.
- Fresh .NET 9/10 consumers pass existing and new observation checks from locally
  packed packages, including real CUDA. Package hashes match the fresh artifacts.
- Unchanged consumers compiled against published 1.0.0 execute with candidate SDK
  DLLs on each runtime, including CUDA; consumer binary/dependency hashes are preserved.
- Relative links in all 21 Markdown files and git diff --check pass.

The two consumer projects use sibling directories to prevent overlapping source
globs. Remote Windows/Linux CI is tracked in
[PR #6](https://github.com/olgerd007/QuantumMatter/pull/6); stable release review
remains pending.
This evidence validates a local candidate, not public publication.

are consumed from fresh packages. PackageConsumer remains limited to 1.0 APIs and
continues to run unchanged baseline-compiled binaries with candidate SDK DLLs.
