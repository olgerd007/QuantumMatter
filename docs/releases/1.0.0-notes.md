# QuantumMatter 1.0.0

QuantumMatter's first stable SDK provides a quantum computing simulator built from
scratch in C# using double-precision System.Numerics.Complex.

## Install

Use matching versions of the Application and Infrastructure packages; Core is
included transitively:

```sh
dotnet add package QuantumMatter.Application --version 1.0.0
dotnet add package QuantumMatter.Infrastructure --version 1.0.0
```

These commands require the packages to have been published. The
[release record](1.0.0.md) tracks promotion and publication status.

## Included capabilities

- Validated circuits, 17 gate kinds, controlled gates and custom single-qubit unitaries.
- Scalar CPU, bounded parallel CPU, optional SIMD and explicit NVIDIA CUDA execution.
- Terminal shot sampling, full-register collapse, allocation budgets and cancellation.
- Deutsch–Jozsa, QFT/inverse QFT and single-solution Grover circuit builders.
- Bit-flip, phase-flip, depolarizing and amplitude-damping noise with seeded trajectories.
- Three packages with XML documentation, frozen API contracts, MIT licensing and
  third-party notices; inward Core/Application/Infrastructure dependencies.

## Compatibility and migration

Libraries target .NET 9 and are checked through package-only .NET 9 and .NET 10
consumers. .NET 10 LTS is recommended for new consumers: Microsoft support for
.NET 9 ends November 10, 2026. CPU release targets are Windows x64 and Linux x64.
CUDA support is Windows x64 with a compatible NVIDIA driver/device; Linux CUDA is
experimental. See the [support policy](../compatibility.md).

Projects and namespaces use QuantumMatter instead of QuantumSim.
StateVectorSimulator and SimulationResult live in QuantumMatter.Application;
callers inject and own their backend. Invalid public basis indices now throw
ArgumentOutOfRangeException. Qubit zero remains the least significant bit; phases,
column-vector ordering, rotation signs and finite radian angles remain contractual.

## Validation and limits

The local Windows Debug and Release suites each pass 664 tests including real CUDA
execution on an RTX 4070 Ti SUPER. Package-only .NET 9/10 consumers also pass CUDA,
CPU, algorithms, noise, cancellation and budget checks. Remote CI and publication
evidence are recorded separately in the release record.

Noise kernels run on CPU, including hybrid CUDA trajectories at unitary boundaries.
This release does not implement mid-circuit measurements/classical feedback,
correlated noise, a density-matrix backend or arbitrary multi-target unitaries.
Resource budgets cover documented arrays rather than all process/device overhead.
Floating-point and seeded random results are not guaranteed bitwise identical
across runtimes or devices. See the [API reference](../api/1.0.0.md) and
[mathematical conventions](../mathematics.md).
