# 1.6 validation and publication record

Candidate version: **1.6.0-rc.1**. Stable promotion and publication are pending.
The user approved deterministic pure-state VQE with gradient descent/backtracking,
explicit stopping/evaluation limits, immutable results, analytic examples and
CPU/SIMD/CUDA/package compatibility validation.

## Scope and implementation

- Application/Variational VqeSolver composes the existing evaluator without Core
  or infrastructure changes, new projects, backend ports or runtime dependencies.
- Immutable VqeOptions, VqeResult and explicit VqeTerminationReason classify
  stationarity, update/evaluation limits and stalled line search.
- Complete circuit-execution accounting includes every occurrence-wise shift.
- Bounded sufficient-decrease backtracking, scaled/log comparisons and preflighted
  overlapping host arrays preserve finite arithmetic and ownership contracts.
- One-/two-qubit demos, independent analytic/dense tests and a sixth package consumer.

All 283 shipped API declarations remain unchanged. There are 33 additive Unshipped
declarations in Application. Assembly binding stays 1.0.0.0, net9.0 library assets
and published 1.0.0 package-validation baseline are retained. Existing five package
consumer sources and public-feed modes remain usable. See the [VQE guide](../vqe.md).

## Validation

Before implementation, restore, a zero-warning Debug build and all 781 CUDA-enabled
cases pass on .NET 9 and .NET 10. All 29 new focused VQE cases pass on both runtimes,
including actual CUDA. Scalar, SIMD-selected and CUDA demos each reach the two
independent known ground energies without relaxing their analytic checks.

Candidate validation on Windows x64, project-selected SDK, actual .NET 9/.NET 10
runtimes and a compatible CUDA device:

- Restore and Debug/Release builds pass with zero warnings or errors.
- All 810 CUDA-enabled cases pass per runtime in Debug and Release.
- Release with hardware intrinsics disabled passes all 810 cases per runtime.
- CPU-only Release passes 720 cases plus one explicit GPU-suite skip per runtime.
- Formatting verification, all 37 Markdown file relative links and diff checks pass.
- Scalar, SIMD-selected and CUDA VQE demos reach -0.2-sqrt(0.58) and -3.
- All three packages validate against published 1.0.0. All six fresh package-only
  consumers pass CPU/SIMD/CUDA checks on .NET 9/10; artifact/cache hashes match.
- Unchanged 1.0.0-compiled binaries execute candidate SDK DLLs on both runtimes
  with CUDA, preserving consumer binary/dependency hashes.
- The updated public-feed checker still passes all five v1.5 consumers on .NET 10
  with CUDA and exact published commit e00722d346b9a0928b5a2aa1cfafa2722616efae.
- All shipped inventories, Core/Infrastructure sources, dependencies and five
  earlier consumer sources remain unchanged. The candidate tag guard passes and
  rejects a stable v1.6.0 tag.

Independent one-qubit eigenvalues and a dense two-qubit Heisenberg eigenpair/residual
validate energies and returned parameters. Tests also verify bounded backtracking,
exact execution-limit boundaries, accepted-iterate ownership, shared/unused and
zero parameters, stationary maxima, large/small gradients, overflow-safe comparisons,
subnormal/stalled steps, exact resource budgets, cancellation and backend failures.
The default sufficient-decrease coefficient is 0.1, requiring meaningful descent;
both analytic examples converge without weakening their numerical checks.

Remote Windows/Linux CI is tracked by the implementation PR. Stable promotion and
publication are separate steps. Local checks do not imply publication. This increment
offers no global-ground-state or universal convergence guarantee; noise/shot
objectives and optimizer extension policies are outside scope.
